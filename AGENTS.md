# Agent instructions

## Repo

Mono-repo for my skills

## Structure

Always place and search skills under `skills` folder:

- `skills/my-skill`
- `skills/my-other-skill`
- ...
- `skills/yet-another-skill`

## Guidelines

* Keep it simple
* Do not repeat yourself
* Generalize skill behaviour - They have to be work for any use cases not for specific ones
* Never place specific skill files under root directory
* Always work in specific skill folder
* Keep `README.md` up-to-date after updates
